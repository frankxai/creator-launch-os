Creator Launch OS

A portable storefront and release workspace for independent creators.

Release candidate. Hosted checkout handoff only; no payment processing, entitlement service or customer database.

Install from a release ZIP

Use Node.js 22 or 24. Extract into an empty directory, open a terminal there and run:

pnpm install --frozen-lockfile
pnpm run dev

Open http://localhost:3000. No real customer data belongs in the sample.

Customize

Read README.md and docs/release/COMPONENTS.md. Keep the authored CSS tokens as the code authority. Export token projections with pnpm run tokens:export.

Verify and build

pnpm verify
pnpm run release:check
pnpm run marketplace:export

Delivery and updates

Commit reviewed changes, then run pnpm run package:release. The ZIP binds its source revision and file hashes. Compare CHANGELOG.md before upgrading. Keep a copy of the previous commit and deployment; revert the PR to roll back these changes.

License and support

MIT source. Retain the included copyright and permission notice. Third-party assets and fonts keep their own notices. Commercial screenshot and marketplace publication approval are separate from source packaging.

Report reproducible problems at repository issues. Include Node version, commit, route and sanitized steps; exclude credentials and personal records.
