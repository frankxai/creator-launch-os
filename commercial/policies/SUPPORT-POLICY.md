# Support policy (DRAFT)

> State: draft. The owner confirms the kit support channel and response time before checkout opens.

## Free core

- Channel: GitHub issues on `frankxai/creator-launch-os`.
- Scope: bugs in the repository, documentation gaps and reproducible deployment failures.
- Response: best effort. No response time is promised.

## Commercial Kit buyers

- Channel: the address on the purchase receipt (decision required: a dedicated inbox).
- Scope: questions about the kit's contents, a delivery link that does not open, refunds and access to updates.
- Response: a first written reply within 2 business days.
- Out of scope: custom engineering, debugging a buyer's own code or merchant account, design work, and live calls.

## What support never does

- Asks for passwords, API keys or merchant credentials.
- Promises sales, conversion or revenue outcomes.
- Issues refunds outside the merchant that took the payment.
