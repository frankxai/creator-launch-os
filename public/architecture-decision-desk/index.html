Cost assumptions and observation state

All example rates, volumes and time values are fictional. Replace them with comparable assumptions. A cash-limit comparison never stops real provider spend.

To add or change observation rows, use the complete JSON below. Keep every failed, rejected and accepted attempt. Imported observations are declarations to inspect, not verified results.

Complete decision JSON

The version-1 schema remains canonical. This editor accepts up to 1 MiB of UTF-8 JSON. An invalid import leaves the current decision unchanged.

Save working JSON keeps incomplete fields without claiming validity. Empty number fields become null. To recover an unfinished file, import it and choose Open rejected JSON for repair, correct the reported fields here, then review and apply. The strict CLI requires a complete valid decision.
