Field notes / The handoff

What did your buyer actually receive?

A customer says the setup instructions are missing. Your source repository contains them. Which file did the customer open?

Start with the exact release ZIP you offered. Its receipt names the source commit, the archive and the files inside it. A matching fingerprint gets you past the question of which edition arrived. The next question is whether a reader can use it.

At the release desk

Commit the product. Run node scripts/package-release.mjs from a clean checkout. Keep the ZIP and its receipt.json together; retain a trusted copy of the receipt at the release source.

At the receiving desk

Download the artifact through the intended delivery route. Get the receipt from the release owner. Check the bytes here, then open the promised file and complete one named task.

Worked case

The sample is the original product contract from commit a6ac97df0800. Use the path docs/PRODUCT-CONTRACT.md in its receipt. After a match, add one space to a copy and check again. That second result should fail.

Run the same check offline

Open index.html in the companion folder. For a terminal check, run the included skill verifier. From the companion directory:

python3 skill/verify-creator-delivery/verify.py
  example/receipt.json example/PRODUCT-CONTRACT.md
  --member docs/PRODUCT-CONTRACT.md

Type the command on one line. Exit 0 means the length and SHA-256 match the selected receipt entry. Exit 1 indicates a mismatch or invalid input.

02 / Verification

Receiving notes / Acceptance

Close the handoff.

Bytes differ
Keep the failed copy and its comparison record. Download the same edition again. A second mismatch goes back to the release owner with the commit and member path. Preserve the original receipt.
Bytes match, task fails
Capture the first failing instruction, platform and observed result. The release owner can now reproduce the content issue against a known edition.
Task succeeds
Ask the recipient to record the output they made, the step they completed unaided and what they would keep. A publisher’s own rehearsal is an internal check.
Handoff note

“I opened [file] from [edition] on [device]. I used it to produce [output]. I could complete [task] without help. The remaining issue is [detail].”
