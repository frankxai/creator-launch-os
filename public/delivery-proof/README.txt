In the workbench choose example/receipt.json, example/PRODUCT-CONTRACT.md, then enter docs/PRODUCT-CONTRACT.md as the member path. Compare and save the record. Add a space to a separate copy and repeat.

Install the complete skill/verify-creator-delivery folder into a project's .agents/skills or .claude/skills. A direct Python invocation from this directory is:
python3 skill/verify-creator-delivery/verify.py example/receipt.json example/PRODUCT-CONTRACT.md --member docs/PRODUCT-CONTRACT.md
